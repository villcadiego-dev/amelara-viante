# Viante

La facu queda más cerca si vamos juntos. Coordiná tu viaje con estudiantes y profesores que van a tu misma facu, a tu mismo horario.

## Páginas
- `index.html` — Home
- `registrate.html` — Registro (mail @alumno.unlam.edu.ar + número de acceso + DNI)

## Cómo verlo
Abrí `index.html` en el navegador, o publicalo con GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

`support.js` es el runtime que hace funcionar las páginas: tiene que quedar en la misma carpeta.

## Tipografía y colores
Ubuntu + Source Serif 4 (Google Fonts). Paleta: #00138C, #00408C, #006B8C, #008C80, #1A008C.
